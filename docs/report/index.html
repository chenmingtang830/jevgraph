JevGraph / project brief
Open source · v0.5.1 · Evidence first

From documents to a bounded candidate graph.

JevGraph replaces open-ended triple generation with local parsing, ontology-aware candidate blocking, typed relation decisions, and deterministic evidence gates.

DocJev / adjacent document evidence
40 documents · 8 packets · single pass

Fast document decisions, with one visible split tradeoff.

In DocJev's published pilot, Jev matched Luna on 40-way document classification and was faster and cheaper on both tasks. Luna was exact on all eight split packets; Jev added one boundary.

Adjacent evidence—not a JevGraph E2E score. JevGraph uses DocJev + LiteParse locally for parsing; its hosted classification and splitting are not invoked by the ingestion command.
