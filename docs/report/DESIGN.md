# Report design contract

The report inherits Proofpress **Boardroom Clarity** for a desktop-first public evidence artifact:
white institutional canvas, warm-paper editorial passages, near-black ink, fine rules, and one
restrained teal accent. DM Sans (with system fallback) carries the reading hierarchy. IBM Plex Mono
(with system fallback) is reserved for versions, cost basis, request settings, and proof metadata.

The narrative follows the DocJev field-report pattern:

1. lead with the recorded finding;
2. make the primary comparison explorable;
3. keep the accuracy tradeoff adjacent to the operational advantage;
4. disclose the shared task and frozen execution;
5. retain failed calls as evidence; and
6. end with the supported claim and its limits.

Cost is presented as cents per 100 planned decisions. Jev's value must always be labeled
`illustrative`; Luna and DeepSeek use the `receipt` label. Cost and latency advantages must never be
restated as a general model-quality ranking. The report remains a single self-contained HTML file
with no API calls or remote runtime dependencies.
